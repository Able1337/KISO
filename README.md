# KISO · IT Exam Lab

Тренажёр для подготовки к экзаменам **ITPEC** и **IPA** уровней **IP (IT Passport)** и **FE (Fundamental Engineer)**. Оригинальные задания, подробные учебные разборы и практика по темам в одном браузерном приложении.

**[Открыть KISO](https://able1337.github.io/KISO/)**

Интерфейс и разборы доступны на **русском, английском и японском**. Задания сохранены на языке первоисточника: английском для ITPEC и японском для IPA.

## Возможности

- **Обучение** — без таймера, с обратной связью после ответа и подробным объяснением. Первый ответ фиксируется.
- **Пробный экзамен** — без таймера и подсказок во время попытки; ответы можно менять до завершения.
- **Экзамен** — с таймером, который продолжает идти после закрытия страницы. Для FE предусмотрены части A/B и пауза между ними.
- **Разбор результатов** — правильные ответы, пропуски, статистика по областям и частям, история попыток.
- **Перемешивание вариантов** — в новой попытке ответы меняют позиции; при продолжении сохраняется прежний порядок.
- **Учебный роадмап** — восемь этапов, 35 тематических блоков, поиск, фильтры и отметки изученного.
- **Практика по темам** — переход от подтемы к исходным заданиям, объяснениям и повторным попыткам.
- **Базовые уроки** — восемь самостоятельных материалов по системам счисления, логике и битовым операциям с примерами и упражнениями.

## Банк заданий

В текущем каталоге **18 наборов и 1384 вопроса**, каждый с учебным разбором на трёх языках.

| Система | Уровень | Наборы | Вопросов |
| --- | --- | --- | ---: |
| ITPEC | IP | Апрель и октябрь 2024–2025, апрель 2026 | 500 |
| ITPEC | FE | Апрель и октябрь 2024–2025, апрель 2026 | 400 |
| IPA | IP | Публикации 2024–2026 | 300 |
| IPA | FE | Демонстрационный комплект 2022 и публикации 2023–2026 | 184 |

IPA FE 2022 содержит демонстрационный комплект A60 + B20. Ежегодные публикации IPA FE содержат по A20 + B6: это подборки опубликованных вопросов, а не полные экзамены. Их таймеры рассчитаны для учебной практики. Публикации IPA IP также не представляют весь закрытый банк CBT.

Роадмап объединяет **1290 подтем и поисковых формулировок**, связанных со всеми вопросами каталога. Практика использует существующие экзаменационные разборы; это не 1290 отдельных авторских уроков.

## Прогресс и данные

Регистрация и серверная база данных не требуются. Прогресс хранится в `localStorage` текущего браузера:

- активная попытка и до 30 завершённых попыток для каждого набора;
- отметки изученных подтем;
- ответы в базовых уроках и тематической практике;
- выбранный язык интерфейса.

Экзамены, самооценка в роадмапе и учебная практика сохраняются отдельно. Для экзаменационных попыток предусмотрена защита от перезаписи устаревшей вкладкой.

Синхронизации между устройствами нет. Очистка данных сайта удалит сохранённый прогресс; локальный запуск и опубликованный сайт имеют отдельные хранилища.

## Локальный запуск

Потребуются **Node.js 22.13+** и **npm**. В GitHub Actions используется Node.js 22.

```bash
git clone https://github.com/Able1337/KISO.git
cd KISO
npm ci
npm run dev
```

Откройте адрес из вывода Vite с путём `/KISO/` — обычно `http://127.0.0.1:5173/KISO/`.

Для стандартного запуска не нужны API-ключи, переменные окружения или повторный импорт экзаменов: данные и ресурсы уже находятся в репозитории.

### Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Локальный сервер разработки |
| `npm test` | Тесты логики попыток, данных, разборов, роадмапа и практики |
| `npm run typecheck` | Проверка TypeScript |
| `npm run lint` | Проверка кода через Oxlint |
| `npm run format` | Форматирование через Oxfmt; изменяет файлы |
| `npm run build` | Статическая сборка в `dist-static/` |
| `npm run build:static` | Явный запуск статической конфигурации сборки |
| `npm start` | Локальный просмотр готовой сборки |

Для просмотра производственной сборки сначала выполните `npm run build`, затем `npm start` и откройте адрес Vite с путём `/KISO/`.

## Устройство проекта

Текущая версия — статическое SPA на **React 19, TypeScript, Vite и Tailwind CSS 4**. Компоненты интерфейса используют Base UI/shadcn и Lucide. Наборы экзаменов и основные экраны загружаются по мере необходимости.

```text
src/main.tsx              Точка входа React
app/page.tsx              Каталог и выбор режима
app/official-exams.tsx    Экзамен, таймер и результаты
app/study-roadmap.tsx     Учебный роадмап
app/topic-study.tsx       Практика на экзаменационных примерах
app/foundation-study.tsx  Базовые уроки
app/*lessons*.ts          Учебные разборы и локализации
components/ui/           Компоненты интерфейса
lib/                     Логика попыток, сохранения, каталога и практики
data/exams/              Структурированные наборы заданий
data/roadmap-index.json  Сгенерированный индекс подтем
public/exams/            Исходные PDF и изображения заданий
scripts/                 Импорт, подготовка ресурсов и проверки контента
tests/                   Автоматические тесты
.github/workflows/       Проверки и публикация GitHub Pages
```

`vite.config.ts` использует конфигурацию из `vite.static.config.ts`. Файлы Next.js/Vinext сохранились в проекте, но текущий запуск идёт через `index.html` → `src/main.tsx`; `app/layout.tsx` не является точкой входа статического приложения.

## Работа с контентом

Экзаменационные наборы описаны в `data/exams/`, каталог — в `lib/exam-catalog.ts`, счётчики готовых разборов — в `lib/lesson-coverage.ts`. При добавлении набора нужно согласованно обновить задания, ресурсы, разборы и метаданные.

После изменения тем разборов пересоберите индекс роадмапа:

```bash
node --experimental-strip-types scripts/build-roadmap.mjs
```

Импортёры и инструменты проверки находятся в `scripts/`. Для обработки PDF используются Python и, в зависимости от скрипта, `pdfplumber`, `pypdfium2`, Pillow. Пути к исходникам и параметры конкретного импорта указаны в скриптах и [истории изменений](RELEASE.md).

Перед публикацией изменений выполните:

```bash
npm test
npm run typecheck
npm run build:static
```

Тесты проверяют ключи, структуру и ресурсы заданий, перемешивание вариантов, таймеры, восстановление попыток и учебный прогресс. Они не заменяют визуальную проверку обрезки изображений и редакционную проверку объяснений на всех трёх языках.

## Публикация

[GitHub Actions](.github/workflows/pages.yml) выполняет установку зависимостей, тесты, проверку типов и статическую сборку при push в `main` или ручном запуске workflow. После успешных проверок содержимое `dist-static/` публикуется на GitHub Pages.

Базовый путь `/KISO/` задан в `vite.static.config.ts`. При переносе на другой адрес нужно также проверить пути ресурсов и метаданные в `index.html`.

## Источники и статус проекта

- [Архив ITPEC IP](https://itpec.org/pastexamqa/ip.html)
- [Архив ITPEC FE](https://itpec.org/pastexamqa/fe.html)
- [Опубликованные задания IPA IP](https://www3.jitec.ipa.go.jp/JitesCbt/html/openinfo/questions.html)
- [Опубликованные задания IPA FE](https://www.ipa.go.jp/shiken/mondai-kaiotu/sg_fe/koukai/index.html)

**KISO — неофициальный учебный проект**, не сервис ITPEC или IPA. Права на оригинальные задания принадлежат их правообладателям. В приложении сохранены ссылки на источники и оригинальные PDF; объяснения и классификация тем являются учебными материалами KISO.

Результат тренировки рассчитывается по учебным критериям и не является официальной экзаменационной оценкой. Известные противоречия официальных ключей отмечены в разборах.
